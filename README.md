# Game-booster-free-fire
Android System Overlay &amp; Optimization Utility using Shizuku
# 🚀 ROG Game Genie - Android Floating Service

Game Booster & Utility overlay khusus Android yang berjalan di atas aplikasi/game menggunakan Shizuku API.

## 📱 Fitur Utama:
- ⚡ **RAM & Cache Optimization:** Pembersihan RAM aman via Shizuku (`trim-memory`).
- 🎯 **Custom Crosshair:** Overlay crosshair untuk game FPS.
- 📐 **Resolution Scaling:** Mengatur resolusi layar secara dinamis.
- 🔋 **System Monitor:** Menampilkan penggunaan RAM & suhu baterai secara real-time.

## 🛠️ Tech Stack:
- Java / Android Native
- Shizuku API Integration
- Android WindowManager (Floating Overlay Service)
